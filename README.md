# Physik-Trainer

Interaktive Lernhilfe für die Physik-Schularbeit: Geschwindigkeit, gleichförmige und beschleunigte Bewegung,
Trägheit und Masse, Kraft und Gewichtskraft, Reibung, Newton'sche Gesetze und freier Fall –
mit anschaulichen Erklärungen, Schiebereglern, Übungsaufgaben und Lösungswegen.

## Lokal starten

```
pip install -r requirements.txt
streamlit run app.py
```
